# CapBar 视觉设计

[账号与设置设计稿](settings-study.html) 对应 CapBar 0.4.0 已实现的五组设置：账号、额度走势、用量、接口、通用。各组内部滚动，沿用额度、走势和用量页的全局宽高及“恢复最小”（448 × 620 pt）；示例尺寸为 462 × 840 pt。原有账号、套餐、额度刷新、外部访问、登录启动与尺寸设置保留；用量组提供自动日志扫描开关、预设或自定义分钟间隔，并通过复选框选择账号页已有目录。目录添加、移除与来源列表同步。HTML 保留交互 mock 和 22 个控件核对项，不写入真实设置；当前原生界面见[用量设置截图](../docs/images/token-usage-settings-usage.png)。

[Token 用量页设计稿](token-usage-study.html) 保存“额度 / 走势 / 用量”三个并列页面的视觉探索，使用虚构数据。0.4.0 原生用量页已实现浅深色、今日 / 近 7 日 / 近 30 日 / 自定义日期范围、工具与账号筛选、每日图表、账号及模型汇总、未定价和无日志状态。详细报表使用独立非模态窗口，默认 1680 × 1000 pt 并适配屏幕，支持按日、月、账号、模型、工具分组，以及多词搜索、数值排序和独立筛选。日志按账号目录调用原样的 ccusage 核心和离线价格；自动扫描默认每 30 分钟，也可手动扫描。当前实现、原生截图与计价口径见[用量指南](../docs/token-usage.md)，HTML 本身不解析日志或计价。

已实现的七日环视觉方案见 [reset-visual-study.html](reset-visual-study.html)。主弹窗并列展示普通账号、仅 5 小时额度为 0%、七日额度为 0% 三种状态，页面另有 16 种额度与探测状态对照。七日额度用尽时，整卡浅红并保留红色“余 0%”，不额外写耗尽提示；5 小时额度不参与七日环进度或整卡告警。所有窗口仍显示具体重置时间。此稿只使用虚构账号。

打开 [capbar-visual-study.html](capbar-visual-study.html) 查看可交互的独立设计稿。HTML 内含样式和演示交互，可直接在浏览器中打开；图片保存在 `assets/`。

新增的 [总走势设计稿](usage-trend-overview-study.html) 展示在“走势”页切换“总走势 / 单账号”：Claude 与 Codex 各自以首账号的七日额度容量为基准，先换算各账号用量，再汇总同一 UTC 绘图区间实际观测到的用量；只有所有账号均缺测的区间留空。曲线默认使用 Google Research Turbo 色阶的柔和节选，页面外提供上一版配色对照。总走势中 Claude 与 Codex 各自按本图实际观测的最低、最高用量映射颜色；单账号走势中同一服务的所有账号共用观测范围。纵轴刻度独立计算，原有额度界面不改。识别方法和仍待验证的换算系数见[容量换算提案](usage-trend-capacity-proposal.md)。该页面使用虚构账号、示例容量系数与曲线；功能分支已实现对应的原生界面。

已确认的刷新、快照与配置规则记录在 [plan.md](plan.md)，可验收的 [v1 规格](spec.md)和 [TDD 实施计划](implementation-plan.md)单独保存。主视觉方向已确认；下方状态对照补充了正常、刷新中、失败保留旧值和首次无快照的界面。

HTML 保存菜单栏弹窗的设计过程；当前交互和布局以原生界面及[使用文档](../docs/README-zh.md)为准。透明材质、系统字体与控件由 macOS 原生组件呈现，允许随系统版本和浅色／深色外观有细微差异。

菜单栏图标素材为 [capbar-menubar-template.png](assets/capbar-menubar-template.png)，运行时按 macOS 模板图像使用。应用图标为 [capbar-app-icon.png](assets/capbar-app-icon.png)，透明外角，构建时转换为 `CapBar.icns`。

设计稿使用虚构账号与示例额度。**页面是静态设计稿，不连接账号，数值不会自行更新。**

设计约定：

- 邮箱作为账号主标识；组织、套餐与配置目录作为辅助信息。无需填写“个人”“工作”等显示名称。
- 默认的 Claude 和 Codex 目录首次自动加入，其他目录可以追加；所有目录都可移除。
- 额度默认只手动刷新；可选“打开弹窗时自动刷新”，按每个账号上次探测时间与共用阈值判断，阈值默认 5 分钟。开启额度走势统计后，应用运行期间按所选间隔采样；本机日志扫描使用独立开关与间隔。
- 额度与走势页顶部“全部刷新”跳过正在刷新的账号；每个账号右侧按钮仅刷新该账号，刷新中禁用。刷新过程保留旧额度并显示 loading。用量页顶部改为“扫描日志”，扫描中或无来源时禁用。
- 每个账号独立显示采集时间：3 分钟内“刚刚”，60 分钟内“X 分钟前”，之后显示具体日期和时间。
- 五小时和七天窗口分别展示剩余额度与各自重置时间。未返回的窗口不显示；本机 Codex 快照只有七天窗口。
- 账号按 Claude 与 Codex 分组；单个账号失败不影响其他账号。

用量页扫描时间集中在扫描按钮下方：最近成功扫描采用与额度页一致的时钟浅底胶囊，颜色按扫描间隔判断（一个间隔内为绿、超过一个间隔为橙、超过两个间隔为红），延迟或过期时补充文字状态；下次扫描使用蓝色。关闭自动扫描时使用灰色，不因手动模式下的旧时间触发调度过期提示。此规则只用于新增日志扫描，现有额度时间分区规则不改。
