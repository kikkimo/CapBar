# CapBar 视觉设计

打开 [capbar-visual-study.html](capbar-visual-study.html) 查看可交互的独立设计稿。HTML 内含样式和演示交互，可直接在浏览器中打开；图片保存在 `assets/`。

已确认的刷新、快照与配置规则记录在 [plan.md](plan.md)。主视觉方向已确认；下方状态对照补充了正常、刷新中、失败保留旧值和首次无快照的界面。

HTML 是最终菜单栏弹窗的视觉基准。实现时应对齐信息层级、尺寸、间距、状态色和交互位置；透明材质、系统字体与控件由 macOS 原生组件呈现，允许随系统版本和浅色／深色外观有细微差异。

CapBar 区域使用 2026 年 9 月 25 日约 16:01 的本机账号与额度快照。**页面是静态设计稿，不连接账号，数值不会自行更新。** 设计稿包含真实账号邮箱，仅适合保存在私有仓库。

设计约定：

- 邮箱作为账号主标识；组织、套餐与配置目录作为辅助信息。无需填写“个人”“工作”等显示名称。
- 默认的 Claude 和 Codex 目录首次自动加入，其他目录可以追加；所有目录都可移除。
- 不在后台定时刷新。默认只手动刷新；可选“打开弹窗时自动刷新”，按每个账号上次探测时间与共用阈值判断，阈值默认 5 分钟。
- 顶部“全部刷新”始终可点，跳过正在刷新的账号；每个账号右侧按钮仅刷新该账号，刷新中禁用。刷新过程保留旧额度并显示 loading。
- 每个账号独立显示采集时间：3 分钟内“刚刚”，60 分钟内“X 分钟前”，之后显示具体日期和时间。
- 五小时和七天窗口分别展示剩余额度与各自重置时间。未返回的窗口不显示；本机 Codex 快照只有七天窗口。
- 账号按 Claude 与 Codex 分组；单个账号失败不影响其他账号。
