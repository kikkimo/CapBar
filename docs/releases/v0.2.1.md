CapBar 0.2.1 fixes provider-wide usage trends and 7-day reset calculations.

- Each total-chart interval now adds the accounts with observed usage. An unavailable account no longer hides data from other accounts; the tooltip lists only contributors observed in that interval.
- When a 7-day reset time is known and usage statistics are enabled, CapBar schedules probes about five minutes before and after the reset, alongside the existing hourly probes near the reset.
- A reset no longer treats unused old-cycle allowance as consumption. Usage observed before and after the reset is counted; the final old-cycle remainder is estimated only when nearby observations show a growth rate that would reach 100% by the reset. Reset-crossing segments remain dashed.
- Existing charts and historical statistics are recalculated from saved SQLite samples. No account history needs to be deleted.

CapBar 0.2.1 修复服务总走势与 7 日重置时的用量计算。

- 总走势的每个区间叠加实际有观测值的账号。单个账号缺测不再隐藏其他账号的数据；悬停气泡只列出该区间有数据的账号。
- 开启用量统计且已知 7 日重置时间时，除重置附近原有的逐小时采样外，还会在重置前、后约 5 分钟各安排一次探测。
- 重置不再把旧周期未使用的额度算作用量。重置前后已观测到的用量照常计算；只有近距离采样的增长趋势表明重置前会用满时，才估算补足旧周期最后一小段。跨重置线段仍以虚线表示。
- 现有走势图和历史统计会从已保存的 SQLite 原始采样重新计算，无需删除账号历史。

### Install / 安装

Download `CapBar-0.2.1.pkg` and `SHA256SUMS` below. Verify the package with `shasum -a 256 -c SHA256SUMS`, then install it on an Apple Silicon Mac running macOS 14 or later. The package installs CapBar at `/Applications/CapBar.app`.

The installer has no Apple Developer ID signature or notarization. macOS may require an explicit choice in Privacy & Security to open the app.
