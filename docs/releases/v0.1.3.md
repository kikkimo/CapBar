CapBar 0.1.3 fixes the folder picker used when adding an account.

- The folder button has a larger clickable area and an accessible name.
- The system folder picker opens in front of the CapBar settings popover. After choosing a folder or cancelling, the settings view remains available.
- No changes to quota probing or stored account data.

CapBar 0.1.3 修复了添加账号时的目录选择体验。

- 文件夹按钮的可点击区域更大，并增加无障碍名称。
- 系统目录选择窗口会显示在 CapBar 设置弹窗前面；选择目录或取消后仍可继续使用设置页。
- 额度探测与已有账号数据不受影响。

### Install / 安装

Download `CapBar-0.1.3.pkg` and `SHA256SUMS` below. Verify the package with `shasum -a 256 -c SHA256SUMS`, then install it on an Apple Silicon Mac running macOS 14 or later. The package installs CapBar at `/Applications/CapBar.app`.

The installer has no Apple Developer ID signature or notarization. macOS may require an explicit choice in Privacy & Security to open the app.
