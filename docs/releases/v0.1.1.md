CapBar 0.1.1 fixes Codex quota refresh when the app is launched from the macOS menu bar.

The macOS GUI provides a minimal `PATH`. In 0.1.0, CapBar could locate an npm-installed `codex` launcher but fail to find its Node.js runtime. This release adds the selected Codex executable directory to the child process environment and discovers common standalone, Homebrew, MacPorts, and Node version manager installation locations. It preserves the existing read-only Codex app-server query.

CapBar 0.1.1 修复了从 macOS 菜单栏启动时，部分 Codex 安装方式无法刷新额度的问题。新版会为 Codex 子进程补齐可执行文件及常见运行时目录，同时保留只读额度查询方式。

### Install / 安装

Download `CapBar-0.1.1.pkg` and `SHA256SUMS` below. Verify the package with `shasum -a 256 -c SHA256SUMS`, then install it on an Apple Silicon Mac running macOS 14 or later. The package installs CapBar at `/Applications/CapBar.app`.

The installer has no Apple Developer ID signature or notarization. macOS may require an explicit choice in Privacy & Security to open the app.
