CapBar 0.2.2 fixes historical usage records when sampling intervals are missing.

- Historical highest and lowest seven-day totals now include windows with missing intervals, counting those intervals as zero.
- Records still use seven consecutive completed local calendar days. Highest daily usage follows the same missing-data rule; the current unfinished day and dates before the first sample are excluded.
- Historical caches rebuild automatically and are invalidated at local midnight.
- Chart gaps and recent observed-usage totals retain their existing behavior.

## 中文

CapBar 0.2.2 修复缺测导致历史用量纪录被排除的问题。

- 历史最高、最低七日合计均允许缺测，缺测区间按 0 参与统计。
- 保持连续 7 个已结束的本地自然日口径；最高单日采用同样规则。不计入当前未结束的当天，也不补入首次采样日期之前的空白。
- 自动重算旧版历史缓存，并在本地跨日后更新缓存。
- 走势图缺测留白、近七日已观测合计的显示规则保持不变。

## Install / 安装

Download `CapBar-0.2.2.pkg` and `SHA256SUMS`. Verify with `shasum -a 256 -c SHA256SUMS`, then install on an Apple Silicon Mac running macOS 14 or later. The CI-built package installs to `/Applications/CapBar.app`.
