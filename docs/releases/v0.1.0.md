CapBar 0.1.0 is the first public release of the macOS menu bar app for viewing Claude Code and Codex usage across local account profiles.

### Highlights

- View remaining quota, reset times, and the capture time for each account.
- Refresh one account or all accounts on demand. Optional refresh on open is off by default.
- Compare fresh Claude statusline and OAuth usage observations, with fallback when only one is available.
- Configure multiple Claude Code and Codex directories, popover dimensions, and launch at login.

### Install

Download `CapBar-0.1.0.pkg` below and install it on an Apple Silicon Mac running macOS 14 or later. The package installs CapBar at `/Applications/CapBar.app`. Verify the downloaded package with `SHA256SUMS`.

This release is built automatically from the tagged source. The app has an ad hoc code signature; the installer has no Developer ID signature or Apple notarization. macOS may require you to explicitly allow it in Privacy & Security. The app is offered as source code and as an experimental unsigned installer.

CapBar reads local Claude Code and Codex configuration directories. A manual Claude refresh starts a short restricted Claude Code session and can consume quota.
