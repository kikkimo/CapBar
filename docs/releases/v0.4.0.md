CapBar 0.4.0 adds local token usage analysis and a standalone usage report.

- A dedicated Usage page alongside Quota and Trends, with today, last 7/30 days and custom date ranges.
- Token breakdowns, API-equivalent USD estimates, daily charts and account/model summaries. Hover details include account contributions; totals use M while token categories retain exact values.
- Reuses the unchanged ccusage 20.0.44 core for Claude Code and Codex logs, separately for each configured account directory. The bundled native engine needs no Node, Rust or system ccusage installation and makes no model calls.
- Manual scans show completed accounts and elapsed time. Automatic scans default to every 30 minutes, with configurable intervals and source checkboxes using existing account directories.
- A separate, nonmodal report window with a larger reading area, search, numeric column sorting and independent filters. Closing it does not close the main window.
- Settings are grouped into Accounts, Quota/Trends, Usage, Access and General, retaining existing quota and account behavior.
- Small private summary caches restore immediately at startup; irrelevant or malformed log records are skipped according to ccusage behavior. Genuine source read failures preserve prior results.

## 中文

CapBar 0.4.0 新增本机 Token 用量统计和独立详细报表。

- 「额度 / 走势 / 用量」三个独立页面；用量支持今日、近 7 日、近 30 日和自定义日期。
- 展示四类 token、API 等价金额、每日柱状图及账号 / 模型汇总。悬浮明细保留分类信息，并列出账号贡献；总数用 M，分类明细保留完整数字。
- 按账号配置目录调用原样的 ccusage 20.0.44 核心，支持 Claude Code 与 Codex。本机分析不调用模型；内置原生引擎，无需另装运行时或 ccusage。
- 支持人工扫描及默认每 30 分钟自动扫描，可设置开关、间隔及勾选现有账号目录；扫描按钮显示账号进度和耗时，附近集中显示上次及下次扫描时间。
- 详细报表为独立非模态窗口，默认 1680 × 1000 pt 并适配屏幕，可缩放、单独关闭；支持检索、数值排序和独立筛选，不影响主窗口操作。
- 设置按账号、额度走势、用量、接口和通用分组，保留原有账号及额度功能和逻辑。
- 仅缓存账号 / 日期 / 模型汇总，启动时快速恢复。按 ccusage 规则跳过无关或损坏记录；真实来源读取失败时保留上次结果。

## Install / 安装

Download `CapBar-0.4.0.pkg` and `SHA256SUMS` from this release. Verify with `shasum -a 256 -c SHA256SUMS`, then install on an Apple Silicon Mac running macOS 14 or later. The package installs to `/Applications/CapBar.app`.

API-equivalent amounts are estimates, not subscription charges or actual invoices. Only logs retained in the selected account directories can be analyzed. Upstream ccusage and dependency licenses are included in the app.
