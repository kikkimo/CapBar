CapBar 0.1.4 makes the seven-day reset easier to read in the quota view.

- A compact seven-day ring shows progress toward the exact weekly reset time.
- A depleted weekly quota gives the account card a pale red background. A depleted five-hour quota does not tint the whole card.
- When the weekly reset time has passed without a new snapshot, CapBar hides the ring and marks the previous value as awaiting refresh.
- Separators beside a tinted account card are removed for a cleaner boundary. Quota probing and stored account data are unchanged.

CapBar 0.1.4 优化七日额度重置时间的呈现。

- 七日环在具体重置时间旁显示当前周期进度。
- 七日额度用尽时，账号卡片显示浅红背景；仅五小时额度用尽时，不改变整张卡片。
- 重置时间已过但尚无新快照时，隐藏七日环，并将旧额度标为“待刷新”。
- 浅红卡片相邻的账号分割线已移除。额度探测和已有账号数据不受影响。

### Install / 安装

Download `CapBar-0.1.4.pkg` and `SHA256SUMS` below. Verify the package with `shasum -a 256 -c SHA256SUMS`, then install it on an Apple Silicon Mac running macOS 14 or later. The package installs CapBar at `/Applications/CapBar.app`.

The installer has no Apple Developer ID signature or notarization. macOS may require an explicit choice in Privacy & Security to open the app.
