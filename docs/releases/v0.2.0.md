CapBar 0.2.0 adds optional usage analysis for Claude Code and Codex accounts.

- Switch between individual 7-day usage charts and a provider-wide total. Totals convert account usage to the first account's subscription capacity before adding it, and are marked as estimates because provider capacity ratios are not verified.
- Hover over a total chart to compare each account's contribution with aligned bars. The charts leave unobserved intervals blank.
- See observed 7-day usage statistics, recent 24-hour change, and historical records for rolling 7-day windows, single days, and intervals. Historical summaries are cached in SQLite and recalculated when samples change.
- Enable usage statistics to sample while CapBar is running. Choose a 1, 2, 3, 4, 6, or 8-hour interval; manual refreshes also add samples. The feature is off by default.
- The total headline now uses the latest fully observed interval. Older samples without subscription metadata no longer create a false chart gap when a later sample records the tier; a confirmed tier change still leaves the affected interval blank.

CapBar 0.2.0 新增可选的 Claude Code 与 Codex 用量分析。

- 可在单账号 7 日走势与各服务的总走势之间切换。合计前会将各账号用量折算到首账号的订阅容量；由于套餐容量比例尚未核实，界面将结果标记为估算。
- 悬停在总走势图上，可用对齐的横条比较各账号贡献；没有完整观测的区间仍保持空白。
- 查看近 7 日已观测用量指标、近 24 小时变化，以及滚动 7 日、单日和单区间的历史记录。历史汇总缓存在 SQLite 中，采样变化后会重新计算。
- 开启用量统计后，CapBar 运行期间按所选的 1、2、3、4、6 或 8 小时间隔采样；手动刷新也会增加采样。该功能默认关闭。
- 总走势卡片显示最近一个完整观测区间。旧样本缺少订阅档位时，不再因为后续样本补充档位而错误断线；明确发生档位变化的区间仍留空。

### Install / 安装

Download `CapBar-0.2.0.pkg` and `SHA256SUMS` below. Verify the package with `shasum -a 256 -c SHA256SUMS`, then install it on an Apple Silicon Mac running macOS 14 or later. The package installs CapBar at `/Applications/CapBar.app`.

The installer has no Apple Developer ID signature or notarization. macOS may require an explicit choice in Privacy & Security to open the app.
