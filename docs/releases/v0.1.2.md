CapBar 0.1.2 adds optional, per-account charts for seven-day quota consumption.

- Enable usage statistics in Settings to start scheduled sampling while CapBar runs. The default interval is four hours; choose one, two, three, four, six, or eight hours.
- Each chart point shows quota consumed during one UTC interval. The chart uses the selected sampling interval, except that one-hour sampling is grouped into two-hour chart points. Dates and hover times use your local time zone.
- Manual refreshes also contribute samples. Missing intervals stay empty; reset-crossing and missing-data connections are dashed. The first complete interval is visible as a point before a line can be drawn.
- Latest quota snapshots remain in JSON; sample history is stored locally in SQLite. Statistics are off by default, and scheduled sampling stops when CapBar quits or statistics are disabled.

CapBar 0.1.2 新增按账号查看的 7 日额度用量走势图。

- 在设置中开启用量统计后，CapBar 运行期间会定时采样。默认每 4 小时采样一次，可选 1、2、3、4、6、8 小时。
- 每个绘图点表示一个 UTC 区间内实际消耗的额度。绘图区间与采样设置一致；1 小时采样按 2 小时绘图。日期和悬停时间按本地时区显示。
- 手动刷新也参与计算。缺测区间不当作 0；跨重置与缺测的连接使用虚线。首个完整区间会先显示单点及数值。
- 最新额度快照仍保存在 JSON，采样历史保存在本机 SQLite。统计默认关闭；退出应用或关闭统计即停止定时采样。

### Install / 安装

Download `CapBar-0.1.2.pkg` and `SHA256SUMS` below. Verify the package with `shasum -a 256 -c SHA256SUMS`, then install it on an Apple Silicon Mac running macOS 14 or later. The package installs CapBar at `/Applications/CapBar.app`.

The installer has no Apple Developer ID signature or notarization. macOS may require an explicit choice in Privacy & Security to open the app.
