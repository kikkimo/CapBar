CapBar 0.3.0 adds local access for external agents through MCP and HTTP/JSON over a Unix socket.

- Query account profiles, quota snapshots, usage trends, statistics and historical records without triggering probes.
- Optionally permit one-shot refreshes with progress, idempotency and shared per-account execution.
- Both access switches default to off. No external account management, configuration changes or scheduling endpoints.
- Local access uses an access key and owner-only files/socket permissions; no TCP port is exposed.
- Includes the native `capbar-mcp` bridge in the application bundle. See [setup instructions](https://github.com/kikkimo/CapBar/blob/main/docs/external-access.md).

## 中文

CapBar 0.3.0 新增 MCP 与基于 Unix socket 的本地 HTTP/JSON 接口。

- 只读查询账号、额度快照、走势、近期统计和历史纪录，查询不会触发探测。
- 可单独允许一次性刷新，支持进度查询、幂等去重及与界面刷新共享账号任务。
- 两个开关默认关闭；不开放账号管理、配置修改或定时任务接口。
- 使用访问密钥及仅当前用户可访问的文件/socket 权限，不监听 TCP 端口。
- App 内置原生 capbar-mcp，无需另装运行时。

## Install / 安装

Download `CapBar-0.3.0.pkg` and `SHA256SUMS`. Verify with `shasum -a 256 -c SHA256SUMS`, then install on an Apple Silicon Mac running macOS 14 or later. The CI-built package installs to `/Applications/CapBar.app`.
